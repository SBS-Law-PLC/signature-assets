## Why this repo exists

The signature kit needs images at stable, publicly-fetchable URLs so recipients on any mail client see the logo, and staff opening the kit locally in Chrome can preview it before installing. Google Drive was tried first and blocked by Workspace admin policy on anonymous access to domain-owned files; GitHub Pages is not subject to that layer.

## Rules

Do not add unrelated assets to this repo. It's scoped to firm-wide signature imagery.

Do not rename files without updating the kit HTML — installed signatures reference the URLs above by exact path.

New assets get added at repo root, not in subfolders.
